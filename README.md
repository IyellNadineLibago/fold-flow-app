# FoldFlow – customer app (Flutter)

Customer-only mobile app for the FoldFlow laundry system. No login.

- **Book a drop-off** – creates a reservation request that appears instantly on
  the staff web dashboard (Reservations page).
- **Track my laundry** – type the Order ID from your ticket (e.g. `ORD-1001`)
  and watch the status move: Received → Washing → Drying → Ready for Pickup →
  Claimed. It updates live whenever staff change the status.

Staff use the web dashboard (separate project); this app has no staff screens.

## Backend: Firebase (Cloud Firestore + anonymous Auth)

The app talks to the same Firebase project as the web dashboard. See
`SETUP.md` at the top of the delivery for the full Firebase setup. For this app:

```bash
flutter pub get
dart pub global activate flutterfire_cli
flutterfire configure          # choose your Firebase project; overwrites lib/firebase_options.dart
flutter run
```

Until `flutterfire configure` has been run the app starts in a local **demo
mode** (nothing is sent to a server).

In the Firebase console, enable **Authentication → Sign-in method → Anonymous**.

## Code map

- `lib/data/laundry_repository.dart` – the interface the screens use, plus the
  in-memory demo implementation (used when Firebase is not configured, and in
  tests).
- `lib/data/firebase_laundry_repository.dart` – the Firestore implementation.
- `lib/firebase_options.dart` – generated by `flutterfire configure`.
